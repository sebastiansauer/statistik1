Erstkontakt

Warum R?

  1. R ist kostenlos — andere Softwarepakete für Datenanalyse sind teuer.
  2. R ist quelloffen — jeder kann die Befehle einsehen und beitragen.
  3. R hat die neuesten statistischen Methoden.
  4. R hat eine große Community.
  5. R ist maßgeschneidert für Datenanalyse.

Allerdings gibt es auch abweichende Meinungen …

Erstkontakt

Definition: Reproduzierbarkeit

Definition: Reproduzierbarkeit

Ein (wissenschaftlicher) Befund ist reproduzierbar, wenn andere Personen mit der Analysemethodik zum gleichen Ergebnis kommen wie in der ursprünglichen Analyse (Plesser, 2018).

Daten + Syntax + genaue Messbeschreibung = reproduzierbar

Erstkontakt

Aus der Forschung: Reproduzierbarkeit in der Psychologie

Obels et al. (2020) untersuchten die Reproduzierbarkeit von Registered Reports (2014–2018):

Von 62 Artikeln hatten 41 Daten verfügbar, 37 Analyseskripte. Für 36 Artikel waren beides verfügbar. Reproduziert werden konnten die Hauptergebnisse von 21 Artikeln.

Insgesamt war also etwa jede dritte Studie reproduzierbar — da gibt es noch viel Luft nach oben.

Installation von R und einer IDE

R und eine IDE installieren

  1. R installieren: https://cloud.r-project.org (Windows/MacOS/Linux)
  2. Eine IDE installieren — Ihre Wahl:

    • RStudio: https://posit.co/download/rstudio-desktop/

    • Positron: https://positron.posit.co/download.html

    • Positron ist neuer und unterstützt neben R auch Python.

Hinweis

Starten Sie nur Ihre IDE, nicht R direkt — RStudio bzw. Positron findet R selbständig und öffnet es “heimlich”.

Installation von R und einer IDE

R-Pakete

Was sind R-Pakete?

  • R hat einen modularen Aufbau: Erweiterungen (“Pakete”) bringen zusätzliche Befehle und Daten mit.
  • Stellen Sie sich ein Paket wie ein Buch vor: Erst installieren (“kaufen”), dann laden (“lesen”).
  • Auf CRAN, dem offiziellen “Web-Store”, gibt es ca. 20.000 Pakete (Hornik et al., 2023).

R-Pakete

Pakete installieren & starten

  • Installieren (einmalig): per Klick (RStudio) oder Code:

    install.packages("tidyverse")

  • Starten (bei jedem Neustart von R neu):

    library(tidyverse)

  • Vor dem Installieren/Updaten: R-Session neu starten (RStudio: Session > Restart R; Positron: Neustart-Button in der Konsole).

  • Für dieses Buch benötigt: tidyverse (Wickham et al., 2019) und easystats (Lüdecke et al., 2022) — beides “Sammelpakete”, die mehrere Pakete auf einmal bereitstellen.

Mit R arbeiten

Projekte

  • Ein Projekt (RStudio) bzw. ein Workspace (Positron, File > Open Folder…) ist letztlich ein Ordner, der als Basis für zusammengehörige Dateien dient.
  • Vorteil: Dateien lassen sich ohne vollständigen Pfad ansprechen, z. B. "daten.csv" statt eines langen Pfads.
  • Nutzen Sie Projekte — das erspart Ärger mit Pfaden.

Mit R arbeiten

Skriptdateien & Quarto-Dokumente

  • Eine Skriptdatei sammelt R-Befehle (“Syntax”) in einer Textdatei.
  • Neue Skriptdatei: File > New File > R Script · Speichern: Strg+S · Öffnen: Strg+O
  • Quarto (in RStudio und Positron integriert) erlaubt es, R-Syntax direkt in Dokumente (HTML, PDF, …) einzubetten — Ausgaben landen automatisch im fertigen Dokument.
  • Sie sind nicht verpflichtet, Quarto zu nutzen — Skriptdateien reichen auch.

Errisch für Einsteiger

Definition: Funktion

Definition: Funktion

Eine Funktion ist eine Regel, die jedem Eingabewert (Argument) einen Ausgabewert zuordnet — eine “Maschine”, die Eingabedaten in Ausgabedaten umwandelt.

Errisch für Einsteiger

Definition: Vektor

Definition: Vektor

Ein Vektor ist eine geordnete Folge von Werten (“Elementen”), erstellt mit der Funktion c().

x <- c(1, 2, 3)
namen <- c("Anni", "Bert", "Charlie")  # Text-Vektor

Errisch für Einsteiger

Unsere erste statistische Funktion

Antworten <- c(42, 43)
mean(Antworten)

R arbeitet verschachtelte Befehle von innen nach außen ab:

mean(Antworten) → mean(c(42, 43)) → 42.5

Errisch für Einsteiger

Funktionsargumente

mean(x, trim = 0, na.rm = FALSE, ...)
  • x: der Vektor, für den der Mittelwert berechnet wird
  • trim: sollen Extremwerte “abgeschnitten” werden?
  • na.rm: sollen fehlende Werte (NA) entfernt werden?
  • Argumente mit Voreinstellung (default) müssen nicht befüllt werden.
  • Ohne Argumentnamen zählt die Reihenfolge: mean(Antworten, 0, FALSE) ✅, aber mean(Antworten, FALSE, 0) ❌ (Fehler).
  • Mit Argumentnamen ist die Reihenfolge egal: mean(na.rm = TRUE, x = Antworten).

Errisch für Einsteiger

Vorsicht bei fehlenden Werten

Antworten <- c(42, 43, NA)
mean(Antworten)          # ergibt NA
mean(Antworten, na.rm = TRUE)  # entfernt NA, rechnet trotzdem

NA steht für not available — R macht damit auf fehlende Werte aufmerksam, statt sie stillschweigend zu ignorieren.

Errisch für Einsteiger

Vektorielles Rechnen

x <- c(1, 2, 3)
x - mean(x)

Eine Operation wird automatisch auf jedes Element angewandt — kein Loop nötig.

Errisch für Einsteiger

Ich brauche R-Hilfe!

  • Hilfe zu einer Funktion: help(fun) oder Help-Panel der IDE
  • In welchem Paket wohnt eine Funktion? RDocumentation durchsuchen
  • Fehler nicht klar? Meist hat schon jemand das Problem gelöst — stackoverflow.com
  • R hängt oder spinnt? Konsole/Session neu starten (AEG-Prinzip: Aus-Ein-Gut)
  • WARNING ist meist harmlos, Error bedeutet: Syntax läuft nicht durch
  • Stundenlang Fehler gesucht? Pause machen — mit Abstand findet man ihn leichter.

Mit Daten arbeiten

Wo sind meine Daten?

Eine Datei liegt entweder

  1. irgendwo im Internet, oder
  2. irgendwo auf Ihrem Computer (z. B. im Projektordner).

In beiden Fällen definieren Pfad und Dateiname den Aufenthaltsort.

Gebräuchlichste Tabellenformate: CSV (einfache Textdatei, mit jedem Texteditor lesbar) und XLSX (Excel).

Unser Beispieldatensatz im Kurs: mariokart (eBay-Auktionen des Spiels Mario Kart, Preise in Dollar).

Mit Daten arbeiten

Daten importieren

# aus einem R-Paket:
data("mariokart", package = "openintro")

# von einer Webseite (read_csv aus dem tidyverse):
mariokart <- read_csv("https://vincentarelbundock.github.io/Rdatasets/csv/openintro/mariokart.csv")

# vom eigenen Computer (Datei im Projektordner):
d <- read_csv("mariokart.csv")
  • Ein R-Paket muss vor der Nutzung installiert sein (häufig vergessen!).
  • Alternativen: read.csv (Standard-R, kein Extra-Paket) und data_read (easystats, liest viele Formate automatisch).

Mit Daten arbeiten

Daten per Klick importieren

  • RStudio: Import-Assistent (From Text (readr) … für CSV, auch Excel und SPSS) mit Vorschau und Optionen zu Trennzeichen, Kopfzeile, Spaltentypen.
  • Positron (seit Version 2026.09): Datei öffnen, auf Import Data klicken — der Dialog zeigt den passenden R-Code (readr, readxl, nanoparquet) und führt ihn per Import in der Konsole aus; keine Tabellenvorschau mit Optionen.

Mit Daten arbeiten

Definition: Dataframe

Definition: Dataframe

Ein Dataframe (auch “Tibble”) ist ein Datenobjekt zur Darstellung von Tabellen: eine oder mehrere gleich lange, benannte Spalten. Jede Spalte ist selbst ein Vektor.

Tabellen ansehen: Namen eingeben (nur anschauen, nicht ändern), View(mariokart) oder Klick auf das Tabellen-Icon im Environment (RStudio) bzw. unter Session > Variables (Positron).

Logikprüfung

Logische Prüfungen in R

x <- 42
x == 42   # Gleichheit prüfen (doppeltes Gleichheitszeichen!)
Prüfung auf R-Syntax
Gleichheit x == Wert
Ungleichheit x != Wert
Größer / kleiner x > Wert / x < Wert
Größer gleich / kleiner gleich x >= Wert / x <= Wert
Logisches UND (x < Wert1) & (x > Wert2)
Logisches ODER (x < Wert1) \| (x > Wert2)

Vorsicht

x = 73 prüft nicht auf Gleichheit, sondern weist zu!

Praxisbezug

Wie man mit Statistik lügt

Die zufriedenen Kunden

10 Kunden sollen ihre Zufriedenheit angeben (1 bis 10) – nicht alle antworten:

Zufriedenheit <- c(9, 8, 10, 9, NA, 8, NA, NA, 9, NA)
mean(Zufriedenheit, na.rm = TRUE)   # 8.8 -- "Unsere Kunden lieben uns!"
sum(is.na(Zufriedenheit))           # 4 -- fast die Hälfte fehlt
  • is.na() prüft jedes Element auf NA; sum() zählt die TRUEs (TRUE = 1)
  • Wer antwortet nicht? Vermutlich eher die verärgerten Kunden.
  • Gedankenexperiment: Hätten die 4 Fehlenden je eine 2 vergeben, sinkt der Mittelwert auf 6.1.
  • na.rm = TRUE ist keine neutrale Einstellung, sondern eine stille Annahme: Die Fehlenden hätten im Schnitt so geantwortet wie die Vorhandenen.

Wie man mit Statistik lügt

Kritisch nachgefragt

Kritisch nachgefragt

  • Wie viele Werte fehlen? Wird das berichtet?
  • Warum fehlen sie? Unterscheiden sich die Fehlenden systematisch von den Vorhandenen?
  • Wie stark ändert sich das Ergebnis, wenn man plausible Werte für die Fehlenden annimmt?

Zusammenfassung

  • R ist kostenlos, quelloffen, aktuell und community-getragen
  • R + IDE (RStudio oder Positron) arbeiten Hand in Hand
  • R-Pakete: einmalig installieren, bei jeder Sitzung neu starten
